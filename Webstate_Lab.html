    Quick guide

    1. Load an example, use Regex → DFA to generate a machine from regular expressions, or choose New DFA.
    2. In the editor, enter comma-separated states and single-character alphabet symbols, or edit generated transitions directly.
    3. The regular expression representing the active DFA is displayed right beside the State diagram title.
    4. Type a test string. Use Step to consume one character, Play to animate, or select a tape symbol or trace row to jump. An empty input tests ε.
    5. The final state decides acceptance. The Trace Coach explains the selected step. Use the Table tab to view δ in grid format.
